# Урок 5 – Person и Student

WPF приложение на C# (.NET 10), което илюстрира понятията клас, обект, наследяване и инкапсулация чрез модела `Person` → `Student`. Базовият клас `Person` съдържа общите свойства `Id` (с `private set`) и `Name`, а производният `Student` добавя специфичното свойство `Grade`. Потребителят въвежда име и оценка във формата, а C# кодът създава обект `Student`, показва данните му и демонстрира как същият обект може да се разглежда като `Person`.
